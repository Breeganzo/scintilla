# Dependencies for the MCP server only.
#
#   pip install -r requirements/mcp.txt
#
# Deliberately NOT folded into base.txt. The MCP server is a separate process
# that talks to the HTTP API, so the API container has no reason to carry the
# protocol SDK - and the MCP process has no reason to carry Django, psycopg or
# the embedding model. Keeping them apart is what makes the MCP server cheap
# enough to co-locate on a 12 GB box.

# The SDK renamed FastMCP to MCPServer in 2.0 and changed several APIs, so the
# lower bound is a real constraint rather than habit.
mcp>=2.1,<3.0
httpx>=0.28,<1.0
